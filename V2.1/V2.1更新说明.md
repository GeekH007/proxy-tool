# V2.1 稳定性增强版

更新日期：2026-10-30

## 版本标识

- 程序显示版本由 V2.0 更新为 V2.1。
- 窗口标题、页面版本标识、托盘提示和诊断报告使用 V2.1。
- 更新了界面预览和 V3.0 计划中的基线版本说明。

## 纳入本版本的功能

- 本机自循环拦截，包括解析到本机监听端口的上游别名。
- 多上游总拨号预算，以及有界 DNS 解析、解析合并和短缓存。
- SOCKS5 的局域网拨号与上游外网 CONNECT 分开计时。
- 全局连接上限、本机保留额度和共享客户端额度。
- 监听异常有限恢复，界面显示恢复中或故障状态。
- 健康检查、上游备注与停用、一键诊断、日志和报告导出。
- 配套上游连接保护、可取消等待队列、轮转日志、有限重启与平稳停止。

这些功能已在此前的稳定性改造中实现，本次将其正式归入 V2.1；本次版本标识更新不改变转发策略。

## 升级兼容

- V2.1 源代码独立放在 `D:\software\V2.1`；`D:\software\V2.0` 已恢复到本轮版本标识更新前的状态。
- 沿用 `%APPDATA%\ProxyToolV2` 及用户指定的配置文件，保留预设、备注和认证信息。
- 开机自启动继续使用历史注册表项名称 `系统代理工具 V2.0`，避免升级后状态丢失或重复注册。
- 单实例标识不变；已有 V2.0 运行时仍可找到旧窗口，避免同时启动两套转发。
- 图标继续从同级 `assets/` 加载。

退出托盘中的旧进程，替换文件后重新启动，窗口即可显示 V2.1。
使用新目录的 `proxy_tool.bat` 启动。如原来已启用开机自启动，在 V2.1 中取消勾选后重新勾选，
让启动项的脚本路径更新到 V2.1；两版继续使用同一个历史启动项，不重复注册。
上游部署仍需四个运行时 JS 文件，并保留各电脑的白名单与端口设置。

## 性能与后续版本

本版本重点是故障等待可控、减少误断开和资源保护。此前测量中，普通 HTTP 小请求存在开销，其他场景有升有降，不能承诺所有访问或下载都会更快。

后台与界面分离、三类入口统一多上游调度和模块拆分属于 V3.0 计划，尚未在 V2.1 实现。
