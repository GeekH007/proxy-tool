# 系统代理工具（proxy_tool）

Windows 桌面小工具：一键开关系统代理、管理多套代理预设、把代理共享给局域网内其他设备（手机/平板），支持托盘常驻与开机自启。

单文件 `proxy_tool.py`，纯 Python 标准库（tkinter + ctypes 调 Win32），**零第三方依赖**。

## 功能

- **代理开关**：写注册表并广播生效，浏览器立即感知，无需重启、无需管理员权限；状态每 2 秒与系统真实状态对齐
- **多套预设**：不同代理地址/端口存成命名预设，下拉即切；点「新增」进入新增模式（输入框清空、代理/共享暂禁用，不影响正在运行的代理和共享），填完点「存预设」保存并退出，Esc / 取消（「删除」临时变身）/ 重选预设可放弃；应用/退出时也会自动保存
- **连通性测试**：一键走当前代理请求 `generate_204`，显示耗时/失败原因（后台线程，不卡界面）
- **局域网共享**：本机开 `0.0.0.0:共享端口`（默认 7891），把收到的连接原样转发给上游代理——透明 TCP 转发，不解协议；手机把代理填成 `本机IP:7891` 即可上网。状态栏实时显示设备数/连接数，可查看客户端明细；共享开关状态跨启动记住，下次启动自动恢复
- **防火墙自动处理**：首次开启自动检测规则，缺失时弹 UAC 一键放行（仅对本机子网）
- **设置页**：共享监听端口可改；配置文件保存位置可切换，切换时自动把当前配置复制到新位置
- **托盘常驻**：点 × 藏进通知区，代理和共享继续跑；左键恢复窗口，右键菜单退出；explorer 重启后图标自愈
- **开机自启**：勾选即注册 HKCU Run（pythonw 静默启动）
- **二次启动单实例**：重复运行会把已开的窗口拉到前台

## 运行环境

- Windows 10 / 11
- Python 3.8+（安装时勾选 *Add to PATH*）

## 快速开始

```bat
:: 方式一：双击
proxy_tool.bat

:: 方式二：命令行
pythonw proxy_tool.py
```

## 局域网共享的使用场景

上游代理（如 `192.130.x.x:7890`）与手机不在同一网段、手机直连不上时：

1. 主界面填上游代理的 IP 和端口
2. 点 **开启共享**（首次会弹 UAC 加防火墙规则，选"是"）
3. 手机的 Wi-Fi 代理设为 **手动**，服务器填本机局域网 IP，端口填 `7891`

共享的转发目标始终跟随主界面当前填写的代理，切换预设即时生效。

## 注意事项

- 首次开启共享会弹 **UAC**（`netsh` 加防火墙规则，仅放行本机所在子网）
- 配置默认存于 `%APPDATA%\ProxyTool\`（`proxy_config.json` 预设 + `settings.json` 应用设置），位置可在「设置」中切换，写盘均为原子替换
- 程序不产生日志文件，不留临时垃圾
- 窗口标题（`系统代理工具`）参与单实例定位，请勿修改 `APP_TITLE`

## 实现要点（给想改代码的人）

- 托盘图标用 `Shell_NotifyIconW` + 自建隐藏窗口自实现；托盘回调处于 Tk 消息泵的 WndProc 重入点，**绝不能碰 tkinter 对象**，统一入队由轮询器执行
- 工作线程 → 主线程只走 `queue` + 50ms 轮询（不调 `root.after`，规避非线程安全 Tcl 构建）
- 托盘右键菜单用 Win32 原生 `TrackPopupMenu`——Tk 自带的 `tk_popup` 真实点击能弹出、能关闭，但**不派发选中**，勿改回
- 真正退出只调 `root.quit()`：`root.destroy()` 不会终止 mainloop（进程会残活），统一销毁放在 `mainloop()` 之后
- `RelayServer` 每连接一线程双向搬运字节；上游 socket 接通后清超时以兼容 keep-alive 长连接；停止共享时强掐所有在途/已建立连接
- 共享端口在防火墙检查/UAC 期间被修改会自动作废旧结果、按新端口重来一轮
- 配置读取失败/损坏时保留现场不覆盖，写盘失败时不动内存状态
